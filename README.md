# 🤖 Nexus → GitHub Release Bot

یک ربات تلگرام که **لینک دانلود مستقیم** یک فایل بزرگ (مثلاً مودِ ۲۰ گیگی از Nexus Mods) رو می‌گیره، تکه‌تکه دانلود می‌کنه، هر تکه رو روی **GitHub Release** آپلود می‌کنه و بعد از هر آپلود توی تلگرام بهت پیام می‌ده.

## ✨ امکانات

- ورودی: **لینک دانلود مستقیم** (نه لینک صفحه‌ی مود)
- دانلود استریم‌شده؛ فایل کامل هیچ‌وقت روی دیسک نمی‌مونه (فقط یک پارت در هر لحظه)
- تقسیم خودکار به پارت‌های `CHUNK_SIZE_MB` (پیش‌فرض ۱۹۰۰ مگابایت، چون سقف GitHub برای هر فایل ~۲ گیگابایته)
- **Retry خودکار** با تأخیر تصاعدی، هم برای دانلود و هم برای آپلود:
  - قطع شدن دانلود → از **همون بایتی که قطع شده** ادامه می‌ده (با هدر `Range`)، نه از اول
  - خطای آپلود → آپلود ناقصِ قبلی پاک و دوباره آپلود می‌شه
- **پیام تلگرام بعد از آپلود هر پارت** (با لینک دانلود همون پارت + درصد پیشرفت کل)
- پیام وضعیت زنده (درصد، سرعت، تلاش‌های مجدد) که دائماً ادیت می‌شه
- `/cancel` برای لغو، و امکان محدود کردن ربات به آیدی‌های مجاز

## 🔄 نحوه‌ی کار

```
لینک دانلود مستقیم → ربات پارت ۱ رو دانلود می‌کنه → آپلود به GitHub → پاک شدن از دیسک → پیام تلگرام
                   → پارت ۲ → ... → پیام نهایی با لینک Release
```

## 🚀 راه‌اندازی

### ۱. ساخت ربات تلگرام
به [@BotFather](https://t.me/BotFather) پیام بده، `/newbot` بزن و توکن رو نگه دار → `BOT_TOKEN`

### ۲. ساخت ریپوی GitHub برای ذخیره‌ی فایل‌ها
- یک ریپوی جدید بساز (مثلاً `nexus-mod-storage`) و **حتماً یک فایل README توش بذار** (ریپوی کاملاً خالی نمی‌تونه Release بسازه).
- پیشنهاد: این ریپو جدا از ریپوی کد ربات باشه.
- از [github.com/settings/tokens](https://github.com/settings/tokens) یک **Personal Access Token (classic)** با اسکوپ `repo` بساز → `GITHUB_TOKEN`

### ۳. کد ربات رو روی GitHub بذار
فایل‌های این پروژه (`bot.py`، `requirements.txt`، `Procfile`، `.gitignore`، `.env.example`، `README.md`) رو توی یک ریپو پوش کن. **هیچ توکن واقعی‌ای توی ریپو نذار.**

### ۴. دیپلوی روی Railway
1. به [railway.app](https://railway.app) با اکانت GitHub وارد شو.
2. **New Project → Deploy from GitHub repo** و ریپوی کد ربات رو انتخاب کن.
3. توی تب **Variables** این مقادیر رو اضافه کن:

| متغیر | لازم؟ | توضیح |
|---|---|---|
| `BOT_TOKEN` | ✅ | توکن ربات از BotFather |
| `GITHUB_TOKEN` | ✅ | توکن GitHub با اسکوپ `repo` |
| `GITHUB_OWNER` | ✅ | یوزرنیم GitHub تو |
| `GITHUB_REPO` | ✅ | اسم ریپویی که فایل‌ها توش آپلود می‌شن |
| `ALLOWED_USER_IDS` | پیشنهادی | آیدی عددی‌های مجاز (با کاما جدا کن). آیدی خودت رو با `/id` بگیر. اگه خالی باشه **هر کسی** ربات رو پیدا کنه می‌تونه ازش استفاده کنه! |
| `CHUNK_SIZE_MB` | ❌ | اندازه‌ی هر پارت، پیش‌فرض `1900` |
| `MAX_RETRIES` | ❌ | تعداد تلاش مجدد، پیش‌فرض `5` |

بعد از ذخیره، Railway ربات رو ری‌استارت می‌کنه.

## 📖 طرز استفاده

1. توی صفحه‌ی مود (سایت Nexus) تب **Files** → **Manual** → **Slow download** رو بزن و صبر کن تا دانلود توی مرورگر شروع بشه.
2. **لینک دانلود رو کپی کن:**
   - Chrome: `Ctrl+J` (`chrome://downloads`) → روی آدرسِ زیر اسم فایل راست‌کلیک → *Copy link address*
   - Firefox: توی پنل Downloads روی فایل راست‌کلیک → *Copy Download Link*
3. دانلود مرورگر رو **Cancel** کن.
4. لینک رو **سریع** به ربات بفرست (لینک‌های Nexus زود منقضی می‌شن).
   - اختیاری: بعد از لینک یک اسم دلخواه برای Release بنویس: `https://... My Cool Mod`
5. ربات بعد از آپلود هر پارت یک پیام با لینک دانلود اون پارت می‌فرسته، و در آخر لینک صفحه‌ی Release رو.

### دستورها
- `/start` یا `/help` — راهنما
- `/id` — آیدی عددی تو
- `/cancel` — لغو کار در حال اجرا (پارت‌های آپلود‌شده روی Release می‌مونن)

## 🧩 ترکیب پارت‌ها بعد از دانلود

همه‌ی پارت‌ها (`name.part_aa`, `name.part_ab`, ...) رو توی یک پوشه دانلود کن:

```bash
# Linux / macOS
cat name.zip.part_* > name.zip
```
```bat
:: Windows (cmd)
copy /b name.zip.part_* name.zip
```

## 🛠 رفع مشکل

| مشکل | راه‌حل |
|---|---|
| `لینک دیگه معتبر نیست (403/410)` | لینک منقضی شده؛ یک لینک تازه بگیر و سریع بفرست. اگه هر بار ۴۰۳ می‌گیری، ممکنه Nexus لینک رو به IP خودت قفل کرده باشه. |
| `این لینک یک صفحه‌ی وب است` | لینک صفحه‌ی مود یا صفحه‌ی HTML فرستادی؛ لینک مستقیم فایل لازمه. |
| `No space left on device` | `CHUNK_SIZE_MB` رو کمتر کن (مثلاً `500`). تعداد پارت‌ها بیشتر می‌شه ولی دیسک کمتری لازم داره. |
| `سرور از Range پشتیبانی نمی‌کنه` | فقط وقتی پیش میاد که وسط دانلود قطعی رخ بده و سرور امکان ادامه نده؛ کار رو از اول شروع کن. |
| خطای ساخت Release (422) | ریپوی GitHub خالیه؛ یک README توش بذار. |
| `توکن GitHub نامعتبره / ریپو پیدا نشد` | `GITHUB_TOKEN` (اسکوپ `repo`)، `GITHUB_OWNER` و `GITHUB_REPO` رو چک کن. |

## ⚠️ نکته‌ها و محدودیت‌ها

- اگه سرور Railway وسط کار ری‌استارت بشه (دیپلوی جدید، کمبود اعتبار...)، کارِ در حال اجرا از بین می‌ره و باید دوباره شروع کنی. پارت‌های آپلود‌شده روی Release می‌مونن.
- ربات هم‌زمان فقط **یک کار** اجرا می‌کنه (چون دیسک مشترکه).
- دانلود ۲۰ گیگ با اکانت رایگان Nexus می‌تونه چند ساعت طول بکشه؛ سرویس Railway باید در این مدت فعال بمونه و اعتبارش تموم نشه.
- GitHub Releases برای **استفاده‌ی شخصی و گاه‌به‌گاه** مناسبه. استفاده‌ی سنگین و مکرر به‌عنوان هاست فایل خلاف قوانین GitHub هست؛ برای مقیاس بالا از سرویس دیگه‌ای (مثل archive.org) استفاده کن.
- به شرایط استفاده‌ی Nexus Mods و مجوز هر مود احترام بذار؛ این ابزار برای استفاده‌ی شخصی ساخته شده.
